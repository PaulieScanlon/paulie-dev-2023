[Observability](https://mastra.ai/docs/mastra-platform/observability) on the Mastra platform now includes a **requests** view for monitoring server health. See total traffic, average and p95 request durations, response status over time, latency percentiles, and high-traffic endpoint counts.

The **requests** view populates automatically for any Mastra server deployed on the platform. Use it to catch failing endpoints, spot latency spikes, and improve your application's performance.

You'll find it under the **Observability** menu in the platform's sidebar navigation.

Before the requests view, monitoring server activity meant wiring up third-party services: (Datadog, Grafana, Sentry, etc.). Now, requests join metrics, logs, traces, and intelligence to give you a more complete view of your application's behavior.

Requests are captured per [environment](https://mastra.ai/docs/mastra-platform/environments). Production, staging, or any custom environments, each show up as their own view.
